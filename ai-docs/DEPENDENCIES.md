# Dependencies

- Version updates require a separate PR, with only code changes necessary to absorb the update.
- Update only for a needed feature, encountered bug, or known security issue.
- Discuss new dependencies with the team first. Record their purpose and trust rationale in `Cargo.toml`.
- Evaluate additions/updates with the [PR dependency questionnaire](../.github/PULL_REQUEST_TEMPLATE.md#dependency-update-questionnaire-only-if-deps-changed-or-added).
